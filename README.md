# Web Calculator

A simple and responsive web calculator built using HTML, CSS, and JavaScript.

## Project Description

This project is a functional web calculator designed to perform basic arithmetic operations with a clean and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear and reset functionality
- Responsive design
- User-friendly interface

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
